# EXP-005 — Chronologically Calibrated ExtraTrees

Status: **COMPLETE — NOT PROMOTION READY**

Pre-registered in issue #44 before results were inspected.

## Frozen contract

- Research cutoff: `2026-08-18`
- Feature set: `v3-features-004-treasury` (53 features)
- Labels: `v3-labels-001`
- Model: `extra_trees_calibrated_v1`
- Classification: fixed ExtraTrees + chronological 80/20 sigmoid calibration
- Return/drawdown: fixed ExtraTrees regressors
- Seed: `42`
- No hyperparameter search or post-result tuning under EXP-005
- Same frozen Treasury dataset and realized-date samples as the prior Treasury tournament
- V3-018 gate version remains `v3-champion-gates-001`
- Sizing remains `1.00x`

## Measured result

EXP-005 ranked first among the compared full candidates, but **ranking is not promotion**.

| Metric | EXP-005 | Prior `UST-EXP-004` | Interpretation |
| --- | ---: | ---: | --- |
| Mean classification Brier | 0.1996 | 0.2249 | improved |
| Mean classification ECE | 0.1096 | 0.1805 | materially improved |
| Mean relative Brier improvement vs base rate | -0.0985 | -0.2622 | improved, but still worse than base rate |
| Positive relative-Brier folds | 0 | 0 | fails robustness |
| Mean return Spearman | -0.0782 | -0.0461 | still negative; worse overall |
| Positive return-Spearman folds | 1 | 2 | fails robustness |
| Mean drawdown Spearman | -0.0354 | -0.0213 | still negative |
| Positive drawdown-Spearman folds | 1 | 1 | fails robustness |

The strongest regression failure is concentrated in 2025: 20-day return Spearman is about `-0.461` and 60-day return Spearman about `-0.559`. The model therefore does not provide reliable return ordering even though its probability calibration improved.

## Absolute prediction gate

Result: **FAIL**

Reasons preserved by the evaluator:

- `classification_worse_than_base_rate`
- `classification_not_robust_across_folds`
- `return_rank_correlation_nonpositive`
- `return_signal_not_robust_across_folds`
- `drawdown_rank_correlation_nonpositive`
- `drawdown_signal_not_robust_across_folds`

`sample_hashes_match = true`, so this is a model-result failure rather than a sample-contract failure.

The tournament's `overall_full_candidate_rank = 1` is only a relative rank among the candidates in that table. It does not override the absolute prediction prerequisite or make EXP-005 eligible for V3-019.

## Decision

Preserve EXP-005 as a documented negative experiment. Do **not** tune its registered parameters after seeing these results. A subsequent experiment must use a new version and a genuinely different prediction formulation if research continues.

V3-019 remains blocked and no champion is selected.
