# FGI-003 — Add an interactive historical market explorer

This is a living ExecPlan governed by `.agent/PLANS.md` and `AGENTS.md`.

## Purpose / Big Picture

A user should be able to filter historical sentiment periods, inspect analogous market outcomes, and compare displayed distributions without writing Python or editing configuration. Interactions must consume published evidence; they must not rewrite research signals or backtests.

## Scope and Non-goals

In scope: read-only historical filtering, accessible charts/tables, explicit time horizons and sample count, selected-date context, export of approved/public data, versioned publication schema and frontend tests. Out of scope: training models client-side, reoptimizing rules, changing v2.1/v3 acceptance criteria, personalized financial advice, brokerage actions, and arbitrary cloud APIs.

## Plan of Work

Inventory the published schemas and define data contracts; create an independent UI module that reads these artifacts. Build a simple date-range/filter model, match it to known historical records without lookahead re-estimation, render charts and a table, show minimum sample support, and provide a documented educational explanation. If React is adopted, isolate it behind a static build that does not call research functions and keep Pages deploy compatibility. Validate fixture-driven results and browser states before broader rollout.
