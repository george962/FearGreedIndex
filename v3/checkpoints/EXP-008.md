# EXP-008 Checkpoint — Fixed Fear & Greed extreme-state hypothesis

## Result

**REJECT — `DO_NOT_ADVANCE_SENTIMENT_EXTREMES_UNDER_EXP_008`.**

The fixed state split was pre-registered before results:

- `EXTREME_FEAR`: `fear_greed <= 25`
- `NEUTRAL_RANGE`: `25 < fear_greed < 75`
- `EXTREME_GREED`: `fear_greed >= 75`

The predictor used only legally mature historical favorable-entry prevalence within the current sentiment state. It was compared with the global training-prevalence reference on the exact EXP-006 realized dates.

## Frozen evidence

- mean relative Brier improvement: **-0.0187**
- positive relative-Brier folds: **1/3**
- mean ROC AUC: **0.5285**
- positive-AUC folds: **2/3**
- minimum fold ROC AUC: **0.4332**
- hypothesized prevalence ordering folds: **0/3**
- state training support: **FAIL** because 2024 had only 49 `EXTREME_GREED` training rows versus the pre-registered minimum of 50
- sample hashes: exact match to EXP-006

Fold AUCs:

- 2024: **0.5514**
- 2025: **0.4332**
- 2026 YTD: **0.6009**

The extreme-fear realized favorable-entry rate is itself unstable across test folds:

- 2024: **83.3%** (6 rows)
- 2025: **31.0%** (58 rows)
- 2026 YTD: **63.6%** (22 rows)

The hypothesized training ordering `EXTREME_FEAR > NEUTRAL_RANGE > EXTREME_GREED` never holds. A static sentiment-extreme rule therefore does not provide robust enough evidence for an extreme-only model.

## Decision

Do not retune 25/75 thresholds under EXP-008. Do not create a production or sizing rule from this result.

The next clean hypothesis is **time adaptation itself**: use a new experiment ID and test one pre-registered recent rolling training window while keeping the EXP-006 target, retained Treasury features, fixed random-forest parameters, test dates, and absolute viability gates unchanged.

Production state remains unchanged: no champion, V3-019 blocked, sizing `1.00x`.
